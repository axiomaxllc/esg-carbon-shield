# Contributing to AXIOMAX ESG Carbon Shield Spec

Thanks for considering a contribution. This repository is the public reference for the AXIOMAX ESG Carbon Shield verification protocol.

## What we accept

- Bug fixes in the reference verifiers (Python, JavaScript, Bash)
- New language implementations (Go, Rust, Java, Ruby, etc.)
- Test vectors covering edge cases
- Documentation improvements
- Security audits (please disclose responsibly to security@axiomaxllc.com)

## What we do not accept

- Changes to the protocol specification (those are governed by AXIOMAX LLC + patent)
- Changes to canonicalization rules (would break existing tokens)
- Modifications to published public keys

## How to contribute

1. Fork this repo
2. Create a feature branch
3. Open a Pull Request describing the change

For security issues: please email security@axiomaxllc.com directly, do not file public issues.
